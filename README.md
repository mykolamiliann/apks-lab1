## Опис проєкту

Проєкт описує AI-агента build engineer для автоматизації розробки та CI/CD
кросплатформного TypeScript-проєкту Hello World. Агент створює структуру
проєкту, налаштовує складання через npm scripts, тестування Vitest і перевірку
GitHub Actions на Ubuntu, Windows та macOS.

## Запуск агента

У Copilot Chat виберіть агента `build-engineer` і виконайте команду `/init`.

## TypeScript-проєкт

Мінімальний Hello World-проєкт TypeScript збирається у каталог `build/` та
запускається командою `npm start`.
